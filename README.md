# Leilões Retro Games

Aplicativo Android para organizar e acompanhar leilões de jogos e consoles retrô publicados em grupos do Facebook.

## Status do projeto

Em desenvolvimento.

## Objetivo

Centralizar os leilões acompanhados pelo usuário, organizá-los por data de encerramento, exibir o tempo restante e emitir notificações antes do término.

Os lances continuam sendo realizados diretamente na publicação original do Facebook.

## Funcionalidades do MVP

- Cadastro manual de leilões
- Listagem de leilões ativos
- Ordenação pelos leilões que encerram primeiro
- Contagem regressiva
- Consulta, edição e exclusão
- Separação entre ativos e encerrados
- Registro de leilões ganhos e não ganhos
- Controle de itens ganhos a pagar
- Notificações antes do encerramento
- Abertura da publicação original no Facebook

## Tecnologias

- Kotlin
- Jetpack Compose
- Material 3
- Room
- Git e GitHub
- Android 8.0 ou superior — API 26

## Armazenamento

Os dados serão armazenados localmente no aparelho. A primeira versão não terá login, servidor ou sincronização online.
